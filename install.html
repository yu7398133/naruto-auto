安装步骤

1

安装 Tampermonkey

前往 tampermonkey.net 安装浏览器扩展。
支持 Chrome / Edge / Firefox / Safari。

2

安装脚本

点击上方「📦 一键安装脚本」按钮，Tampermonkey 会自动弹出安装确认。
或者手动：Tampermonkey 面板 → 添加新脚本 → 粘贴 naruto-auto.user.js 内容 → 保存。

3

打开云游戏页面

访问 腾讯云游戏 - 火影忍者
手动登录一次（后续会自动检测登录态）。

4

开始使用

进入游戏后，右上角会出现控制面板。
点击 ▶ 开始 执行所有任务，或使用快捷按钮分类执行。
点击 🎯 录制 可进入坐标录制模式，实时校准坐标。

⚠️ 注意：当前坐标为估算值，首次使用请先进入「🎯 录制」模式校准关键坐标。 使用坐标标定工具（coord-calibrator.html）可离线标定。
