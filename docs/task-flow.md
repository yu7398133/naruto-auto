# 任务流程参考文档

> 每个任务的预期 UI 流程、关键坐标、等待时间
> 用于开发和调试时参考

## 通用约定

- 所有坐标基于 **1280×720** 分辨率
- 等待时间单位为毫秒 (ms)
- `[检测]` 表示需要画面确认的步骤
- `[可选]` 表示可能不存在的步骤（如弹窗）

## 通用前置操作

每个任务执行前：
1. 关闭可能存在的弹窗（活动公告、签到弹窗等）
2. 确认当前在主界面（底部导航栏可见）

## 战斗等待策略

当前采用固定延时（30-120s），后续优化方向：

1. **像素采样法**：定期截图检测特定区域颜色变化
   - 战斗中：画面频繁变化
   - 战斗结束：出现"胜利/失败"字样区域
   - 结算界面：固定 UI 元素出现

2. **OCR 法**：识别画面中的文字
   - 检测"胜利""失败""领取""确认"等关键词

3. **差异检测法**：比较连续帧的差异
   - 战斗中：差异大
   - 战斗结束：差异趋近于零

## 弹窗处理优先级

游戏启动后可能出现的弹窗（按频率排序）：

| 弹窗 | 关闭方式 | 坐标 |
|------|----------|------|
| 活动公告 | 右上角 X | (1200, 80) |
| 签到奖励 | 点击任意位置 | (640, 400) |
| 版本更新 | 确认按钮 | (640, 500) |
| 网络提示 | 确认按钮 | (640, 450) |
| 限时活动 | 右上角 X | (1230, 40) |
